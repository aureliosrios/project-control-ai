Manual de Prompts: Sincronización Excel y Dashboards

Flujos de trabajo para sincronizar Google Sheets, exportar a JSON estructurado y actualizar dashboards de construcción locales de forma dinámica.

01. Introducción a la Automatización Excel-JSON

En esta sesión nos enfocamos en la **eliminación de entradas manuales**. En lugar de copiar y pegar datos de presupuestos o cronogramas, establecemos un flujo donde el archivo Excel o Google Sheet actúa como la **base de datos central**, la cual es compilada automáticamente a un archivo **JSON** y consumida por dashboards interactivos (HTML) en tiempo real.

02. El Flujo de Trabajo Técnico

El flujo implementado consta de tres etapas principales:

Paso Origen Destino Herramienta de Sincronización
1 Google Sheets / Excel (.xlsx) Google Drive (Nube) Google Drive Sync Client
2 Google Sheets (Tabla) data_central.json Google Apps Script / Python parser (Codex)
3 data_central.json (Estructura) Dashboard Local (.html) JavaScript dinámico (DOM / Fetch API)

03. Plantillas de Prompts de Automatización

Prompt A: Generador de Script Python Parser (Excel a JSON)
Actúa como un Desarrollador Python y Analista de Datos experto en automatización. Genera un script en Python 3 que lea un archivo Excel local llamado "presupuesto.xlsx". El script debe realizar las siguientes tareas: 1. Leer la primera pestaña del archivo utilizando "pandas" o "openpyxl". 2. Normalizar las columnas: limpiar espacios en blanco, convertir a minúsculas y quitar tildes/acentos de las cabeceras (ej: "Descripción" -> "descripcion", "Metrado" -> "metrado"). 3. Filtrar las filas vacías en la columna "item" o "codigo". 4. Exportar el resultado a un archivo JSON limpio y ordenado llamado "data_presupuesto.json" en formato utf-8. RESTRICCIÓN CRÍTICA: Asegúrate de manejar correctamente la codificación para caracteres especiales en español (ñ, tildes) y retorna únicamente el código del script de Python listo para usar.
Prompt B: Inyección Dinámica de JSON a Dashboard HTML
Actúa como un Desarrollador Frontend experto en Vanilla HTML y CSS. Tengo un archivo JSON local llamado "data_presupuesto.json" con la siguiente estructura de ejemplo: [ { "item": "01.01", "descripcion": "Obras Provisionales", "metrado": 1.0, "unidad": "glb", "precio_unitario": 2500.0, "parcial": 2500.0 }, { "item": "01.02", "descripcion": "Demolición manual", "metrado": 85.0, "unidad": "m2", "precio_unitario": 45.0, "parcial": 3825.0 } ] Genera el código JavaScript necesario para: 1. Realizar una petición fetch() para leer el archivo "data_presupuesto.json". 2. Iterar sobre el array de objetos e inyectar dinámicamente las filas en un elemento con el id "tabla-presupuesto". 3. Formatear los valores numéricos de "precio_unitario" y "parcial" como moneda en Soles (S/. 0.00). 4. Calcular el subtotal total sumando todos los parciales y mostrarlo en un div con id "total-presupuesto". Entrega únicamente el script de JavaScript encerrado en etiquetas
