Temario y Conceptos Clave de la Sesión

1. Ecosistema de Agentes y Gestión Eficiente de Tokens

Análisis de las capacidades de Antigravity frente a otros agentes como Codex y Claude. Por qué Antigravity es ideal para presupuestos y expedientes técnicos de gran volumen sin sufrir agotamiento rápido de cuota.

2. Notificaciones y Modos de Autonomía de la IA

Configuración del nivel de confirmación de planes (Opción 3) para reducir interrupciones durante la generación masiva de código o análisis de datos.

3. Transformación de PDF a Markdown (.md) y JSON

Demostración práctica de cómo convertir catálogos de costos y especificaciones de PDF a Markdown y JSON, logrando que los LLMs analicen partidas y costos sin alucinaciones.

4. De Prompting Manual a Skills en Python

El camino para pasar de un presupuesto aproximado ("torpe") a un sistema automatizado en Python con librerías ejecutivas (`pandas`, `openpyxl`) para cálculo exacto de APUs.

Herramientas Utilizadas en Clase

Antigravity AI (Google)

Agente principal de desarrollo e ingeniería de datos. Soporta amplios contextos de tokens y ejecución local con visualización en tiempo real.

Codex / ChatGPT (OpenAI)

Asistente secundario para consultas rápidas de sintaxis y prototipado de lógica.

Markdown (.md)

Formato de texto ligero ideal para alimentar bases de conocimiento a los agentes de IA.

JSON Format

Estructura estándar flexible para almacenar presupuestos, partidas, insumos y especificaciones técnicas.

Biblioteca de Prompts Recomendados

Prompt 1: Conversión de PDF/Texto de Revista de Costos a JSON Struct
Actúa como un Ingeniero de Costos y Presupuestos. Convierte el siguiente fragmento de tabla de costos a una estructura JSON limpia con las claves: codigo_item, descripcion, unidad, precio_unitario_soles, fecha_actualizacion. Asegúrate de formatear los números a float sin símbolos de moneda.
Prompt 2: Generador de Especificaciones Técnicas (EETT) Estructuradas
Genera la Especificación Técnica para la partida "[NOMBRE_DE_PARTIDA]". Incluye obligatoriamente: 1. Descripción del Trabajo, 2. Calidad de los Materiales, 3. Método de Ejecución, 4. Unidad de Medida y Forma de Pago. Usa formato Markdown limpio.
