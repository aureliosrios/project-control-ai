01. Fundamentos de Formatos en IA

En esta sesión inaugural, el docente sentó las bases para el trabajo profesional con agentes inteligentes. Explicó que el uso tradicional de la IA a través del navegador (la nube) limita la eficiencia y el control de los datos. La tendencia moderna es trabajar en local utilizando formatos estructurados.

Markdown (.md) Sintaxis Limpia

Es el formato idóneo para estructurar especificaciones técnicas (EETT). Los modelos de lenguaje comprenden mejor las jerarquías de títulos (#, ##), negritas y listas en Markdown que en formatos complejos como Microsoft Word.

JSON (.json) Datos Estructurados

Representa el estándar de transferencia de datos en ingeniería. Ideal para presupuestos, estructurando partidas, códigos, precios y cantidades que luego pueden exportarse limpiamente a bases de datos o Excel.

HTML (.html) Visualización Interactiva

Permite a los ingenieros empaquetar resultados y crear cuadros de control interactivos, cronogramas interactivos y reportes dinámicos que se pueden visualizar de manera premium en cualquier navegador web.

02. Entorno Local & Software de Trabajo

Se introdujeron e instalaron dos herramientas esenciales para ejecutar los flujos de trabajo locales sin depender de las interfaces web estándar:

💻 Codex (Desktop Client)

Un cliente liviano instalado directamente en el computador. Evita las interrupciones habituales de las sesiones web y permite gestionar el historial de prompts localmente, mejorando el flujo de trabajo continuo del ingeniero.

🤖 Openco (Open Code Client)

Aplicación de código abierto completamente gratuita que permite conectar múltiples modelos de lenguaje locales y en la nube. Soporta modelos de proveedores globales y asiáticos (como DeepSeek o Qwen).

⚠️ Importante: Los modelos libres en Openco carecen de la flexibilidad contextual de ChatGPT o Claude. Por tanto, requieren que los prompts de instrucción sean sumamente minuciosos, estructurados y detallados para evitar alucinaciones.

03. Biblioteca de Prompts de Clase

Usa estos prompts estructurados en tus clientes locales para generar las plantillas del curso:

Prompt 1: Conversión de Partida de Presupuesto a JSON

Actúa como un Ingeniero de Costos experto. Convierte el siguiente texto informal de una partida de obra en un objeto JSON limpio y bien estructurado. El JSON debe contener exactamente las siguientes propiedades: { "item": "código de partida", "descripcion": "nombre de la partida", "unidad": "unidad de medida", "metrado": valor numérico, "precio_unitario": valor numérico, "moneda": "PEN", "subtotal": metrado * precio_unitario } Texto a convertir: "Partida 02.01.03 de concreto para zapatas con resistencia 210 kg/cm2, volumen calculado de 45.5 metros cúbicos, costo unitario por metro cúbico es de 380 soles"

Prompt 2: Generación Estructurada de Especificación Técnica (Markdown)

Actúa como un Ingeniero Civil especialista en Especificaciones Técnicas (EETT). Escribe la especificación técnica en formato Markdown (.md) para la partida que te indicaré. Sigue esta estructura jerárquica obligatoria usando cabeceras de Markdown: # ESPECIFICACIONES TÉCNICAS ## [Nombre de la Partida] ### 1. Descripción ### 2. Materiales y Equipos ### 3. Método de Construcción ### 4. Método de Medición y Aceptación ### 5. Bases de Pago Partida: "Pintura látex en muros interiores con dos manos"
